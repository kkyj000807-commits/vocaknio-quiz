# 편입 실전 어휘·논리 출제

목적은 번역 재인 자체가 아니라 **새 지문에서 단어·숙어의 뜻을 좁히고 근거에 맞는 답을 고르는 능력**이다. 숙어 미완성 범위를 먼저 처리하고, 이후 일반 단어도 같은 의미 단위 계약을 사용한다.

## 근거와 추론의 경계

작업 전 `references/teaching-evidence.md`를 읽는다. 정병권·이원준의 공개 설명에서 확인된 원칙과 이 앱의 독자적 설계를 구분한다. 비공개 암묵지를 복원했다거나 강사가 인증했다고 쓰지 않는다. 강의 말투·유료 문제·교재 해설을 복제하지 않는다.

## 의미에서 문제까지

1. **뜻 고정**: 표제어뿐 아니라 품사·구문·해당 문맥의 뜻을 고정한다. 독립 편집 출처 2개를 대조한다. The Free Dictionary가 Collins를 전재하면 두 독립 근거로 세지 않는다. 출처 불일치는 다수결로 덮지 말고 뜻을 분리하거나 보류한다.
2. **이해 고리**: 직역 가능한 이미지 → 이미지와 실제 뜻의 연결 → 자연스러운 한국어 해설을 쓴다. '초월번역'은 원문의 부정·수량·가능성·주체·인과를 보존하는 쉬운 풀이이지, 이야기를 덧붙이는 허가가 아니다. 역사적 어원이 확인되지 않으면 **학습용 이미지·어원 아님**으로 표시한다. 이미지가 도움 안 되는 단어에 억지 어원을 만들지 않는다.
3. **문맥 역할**: 연결 관계(예시·대조·양보·동일 원리), 범위/정도, 조건, 원인/결과, 시점, 관점 중 실제로 답을 가르는 것만 고른다. 모든 지문을 찬성/반대의 이분법으로 납작하게 만들지 않는다.
4. **의미 이웃**: 같은 뜻에서 대체 가능한 영어 풀이, 가까우나 초점이 다른 표현, 반대 표현을 구분한다. 교체 조건·구문 제약을 적는다. 동의어 두 개가 같은 문맥에서 맞으면 둘을 경쟁 정답으로 만들지 않는다. 근거 없는 강도 서열을 만들지 않는다.
5. **새 문맥 출제**: 기존 예문을 이름만 바꾸어 재탕하지 않는다. 목표 표현을 뺀 채로도 배경 상식만으로 정답이 정해지거나 정답 선택지가 혼자 긴지 검토한다. 한 문항은 한 판단을 검사한다. 해당 뜻의 제약을 드러내는 자연스러운 문맥을 먼저 만들고 답을 정한다.
6. **해설**: 정답의 지문 내 근거를 짧게 집고, 그 근거가 허용하는 결론과 허용하지 않는 결론을 분리한다. 각 오답에는 정확히 어디서 의미가 변했는지, 어떤 문맥이라면 맞을 수 있는지를 설명한다. '지문에 없으므로 무조건 틀림' 대신 명시 사실·필연 추론·가능성·외부 지식의 차이를 구분한다.
7. **전이 점검**: 뜻을 방금 본 뒤 푼 연습은 숙달 증거로 세지 않는다. 이후 다른 소재의 보지 않은 문맥에서 정확도·응답 시간·같은 오류 유형의 반복을 측정해야 효과를 주장할 수 있다. 엔진의 최근 정답 중복 억제와 범위 순환을 보존한다.

## 출제 전 통과 조건

### 구성 요소별 부연

`data/expression-composition.json`에 단어·전치사·부사적 소사의 역할 → 결합 전체의 뜻 → 일반화하면 안 되는 점을 기록한다. up/out 같은 소사를 전부 전치사라고 부르지 않는다. 합성적으로 이해되는 부분과 표현 전체로 익혀야 하는 뜻을 나눈다. 특정 전치사 하나가 늘 동일한 뜻을 만든다고 설명하지 않는다. 기존 사전 검수의 뜻을 벗어나지 않으며 어원 가설은 검증된 역사로 표시하지 않는다.

`references/question-contract.md`의 반례 점검을 수행한다. 문항 선택지마다 성립 여부를 별도로 평가하고 **정답 1개**를 보장한다. 서로 다른 뜻/품사의 혼용, 부정 범위 역전, 가능→확실 강화, 예시→보편 법칙, 시간→인과 강화를 우선 검사한다. 애매하면 해설로 우기지 말고 문맥/선택지를 고친다.

이 프로젝트의 구현은 `data/reasoning-lessons.json` → `scripts/lib/reasoning-lessons.mjs` 검증/목록 연결 → 버전별 깊이 학습 JSON → `components/reasoning-practice.tsx`다. 기존 사전 대조 자료와 별개로 창작 문제임을 표시한다. 새 항목을 추가한 뒤 빌드 검증과 행동 테스트를 실행한다. JSON 모양 검사만으로 의미 검수/교육 효과를 주장하지 않는다.

## 적용 경계

- 기존 문제 정답 공개 전이나 단어장 뜻 가림 중에는 해설·연습 답을 노출하지 않는다.
- 미색 배경, 세로 스크롤, 큰 터치 영역, 이전/다음 버튼을 보존한다. 자세한 해설은 선택 후 펼친다.
- 연습 기록과 본 문제 풀이 성적을 섞지 않는다. 저장 범위가 기기 로컬이면 그대로 알린다.
- 이 스킬은 승인·배포 권한을 추가하지 않는다. 프로젝트의 `docs/AI_WORK_RULES.md`와 현행 사용자 지시를 따른다.
- 보고는 **확인된 교육 원칙 / 독자적 설계 / 실제 적용 수 / 미검증 효과**를 분리한다. 전체 숙어가 끝나지 않았다면 '전 범위 완료'라 하지 않는다.
