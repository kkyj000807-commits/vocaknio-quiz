## 상태 정의
- **verified**: 이 원문과 문항·선지 대조 완료 → 앱에서 '기출 원문' 라벨 허용
- **unverified**: 원문 미확보/미대조 → '출처 검수 대기'
- **reconstructed**: 강의자료 기반 재구성 → '재구성 예문', 기출 집계 제외
- **blocked**: 오류·복수정답 → 출제 차단
