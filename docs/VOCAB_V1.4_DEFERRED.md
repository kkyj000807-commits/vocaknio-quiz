## 1.4 영영 정의·미국식 발음

- 앱 내장 원문은 Open English WordNet처럼 재배포가 허용된 정본을 우선한다.
- Oxford·Cambridge·Merriam-Webster 등은 무료 열람이나 제한 API가 곧 원문 재배포 허가를 뜻하지 않으므로 교차검증 용도로만 사용한다.
- 표제어 → 품사 → 뜻 번호를 연결하고, 한국어 해설을 별도 검수한다.
- 동형이의어와 다의어를 구분하지 못한 정의는 배포하지 않는다.
- 단어장과 문제 해설은 같은 정의 ID를 사용하고 터치하면 펼쳐지는 한 컴포넌트로 표시한다.
- 데이터 출처·라이선스·버전을 앱 정보와 데이터 메타에 기록한다.
- 미국식 실제 녹음은 Commons의 개별 파일 허가·저작자·미국 지역 표기가 모두 확인될 때만 연결하고, 없으면 미국 영어 합성음을 사용한다.

## 후속 우선순위

1. 실제 Chrome과 iOS Safari에서 Production 1.4의 해설 펼침·미국식 발음·좌우 넘김·세로 스크롤을 확인한다.
2. 현재 40개 공개분과 같은 기준으로 검수 대기 후보를 점진 확장한다.
3. 적응형 기록의 Safari·Chrome·기기 간 동기화 방식을 정한다.
4. 개인 혼동 이력을 오답 선지 구성에도 반영할지 안전 기준과 테스트를 만든다.
5. 같은 표제어인데 동의어 답 목록이 서로 완전히 다른 65개 그룹을 품사·뜻 단위로 추가 검수한다.
6. 레거시 `tests/vocab.test.ts`의 삭제 API 3개를 현재 v1.4 API 테스트로 교체한다.
