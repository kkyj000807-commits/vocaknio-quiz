# VOCA NEXUS v1.4 후속 작업 목록

## 제품 기준

- 이 앱은 주 학습 교재가 아니라 알바 휴식이나 식사 중 5~10분 동안 쓰는 보조 도구다.
- 1순위는 오답 판정, 잘못된 뜻, 다의어 혼합, 동의어 중복 정답처럼 시험에 직접 손해를 주는 오류다.
- 2순위는 빠른 시작, 짧은 기본 세션, 현재 위치 유지처럼 즉시 가능한 편의성이다.
- 아래 항목은 비용이 크거나 선행 작업이 필요한 3순위 보류 작업이다.

## 현재 차단 사항

현재 Codex의 Windows 샌드박스가 OneDrive 아래 기존 파일을 `apply_patch`로 열 때 다음 오류를 낸다.

`windows elevated sandbox cannot reopen writable descendants under read-only carveouts`

따라서 신규 파일은 추가할 수 있지만 `app/quiz.tsx`, `app/wrong-quiz.tsx`, `app/(tabs)/index.tsx`, `lib/store.ts`, 기존 테스트와 같은 파일에는 새 데이터와 공통 엔진을 연결하지 못했다. 임시 파일 복사나 셸 덮어쓰기는 사용하지 않는다. 후속 작업은 저장소를 OneDrive 밖의 승인된 개발 경로에서 열거나 샌드박스 쓰기 범위를 정상화한 뒤 진행해야 한다.

## 적용 완료

- v1.4 정본 38,163개를 기존 `assets/vocab.json`과 병렬로 보존하는 데이터와 메타데이터
- 최종 조판 원본 SHA-256과 행 수, 섹션 수를 확인하는 재생성 스크립트
- 뜻 단위로 확인된 동의어만 허용하고 관련 동의어를 오답 선지에서 제외하는 공통 퀴즈 엔진
- 동의어 자체의 정확한 뜻을 함께 표시할 수 있는 공통 컴포넌트
- 기존 북마크, 오답, 마스터 번호를 원본과 미해결 목록으로 보존하는 순수 마이그레이션 도우미
- 정본 구조, 뜻 연결, 단일 정답을 검사하는 전용 테스트 자산

## 아직 미적용

- 기존 퀴즈 및 오답 복습 화면을 공통 퀴즈 엔진으로 전환
- 홈 화면의 고정 DAY/100단위 범위를 v1.4 실제 섹션으로 교체
- 단어장, 결과, 북마크, 오답 화면의 동의어 표시를 공통 컴포넌트로 통합
- 앱 시작 시 북마크, 오답, 마스터 번호 마이그레이션 실행 및 백업 저장
- 기존 테스트의 9,517개 모의 데이터 의존 제거
- 짧은 10문제 기본 세션과 핵심 파트 중심 홈 화면 적용

## 후속 실행 순서

1. 기존 파일을 `apply_patch`로 수정 가능한 작업 경로를 확보한다.
2. 퀴즈 및 오답 복습 화면을 `lib/quiz-engine.ts`로 전환한다.
3. 홈 범위와 공통 동의어 표시를 연결한다.
4. 저장소 마이그레이션을 백업 우선으로 연결한다.
5. 전체 타입검사, 테스트, 웹 빌드, 모바일/데스크톱 UI 검증을 수행한다.
6. 실제 서비스 확인 뒤에만 Private/Public 저장소 분리를 진행한다.
