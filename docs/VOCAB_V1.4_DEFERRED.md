# VOCA NEXUS 남은 작업

현재 공개 버전과 확인 근거는 WORKING_CONTEXT.md를 기준으로 한다. 현재 Production은 1.7이다.

## 1. 숙어 — 최우선

- 숙어는 핵심 탭과 단어장 첫 칸으로 공개 반영됐다. 전체 구간 안에만 숨기지 않는다.
- 기본 뜻의 빈 값·쪽수만 남은 20개 항목은 1.5에서 복구했다.
- 1.6에서 17개 추가 표현/43개 행, 1.7에서 12개 추가 표현/36개 행의 해설·예문을 보완했다. 전체 1,877개 고유 표제어의 숙어·표현 해설 완료와 혼동하지 않는다.
- 미연결 숙어의 뜻·해설·예문부터 확장한다. 품사·뜻 단위를 확인하고, 반복 행을 같은 근거로 연결한다.
- 기존 Claude 후보는 구 번호이므로 번호로 가져오지 않는다. 실제 표제어·품사·뜻 대조가 필요한 참고 자료다.
- Oxford·Collins·Merriam-Webster 등 무료 열람은 원문 재배포 허가가 아니다. 사전 대조 후 자체 한영 해설·예문 또는 재배포 허가된 원문만 수록한다.

## 2. 실제 기기 확인

- 실제 Windows Chrome 공개 1.7에서 일반 새로고침으로 버전·시각 갱신, 숙어 첫 칸/기본 선택, 검색, 새 뜻·해설·예문·출처 펼침, 세로 스크롤·미색을 확인했다. 인앱 Chromium의 10문제 진입·답변·이전/다음 검증은 직전 1.6에서 수행했다.
- 실제 iOS Safari/모바일 Chrome에서 최신 버전·시각, 세로 스크롤, 좌우 이동, 뜻 가림·복원, 발음, 새로고침 뒤 저장을 확인해야 한다.
- 해설 내용이 표시된 뒤 로딩 문구가 남는 현상이 Windows Chrome에서 관찰됐다. 패널 로딩 상태 종료·재시도 처리를 다음 UI 점검에 포함한다.
- 실제 공개 URL에서 관찰하지 못한 동작은 완료라고 보고하지 않는다.

## 3. 정확성·저장·전체 검사

- 동일 표제어지만 동의어 답 목록이 서로 겹치지 않는 65개 그룹은 품사·뜻 단위 추가 검수 대상이다.
- 적응형 기록은 로컬 전용이며 Safari·Chrome·기기 간 동기화가 없다.
- 개인 혼동 이력을 출제 대상 선정뿐 아니라 오답 선지 구성에 반영하는 작업은 남아 있다.
- 전체 tsc의 tests/vocab.test.ts 구 API import 3개를 현재 v1.4 엔진 테스트로 교체해야 한다. 기존 실패를 숨기려고 테스트를 삭제하지 않는다.
- Pages의 과거 404.html 복구 동작은 별도 점검 대상이다.
- 사용자 tmp/pydeps2 권한 오류를 일으키지 않게 테스트 검색을 --dir tests로 한정한다. 사용자 파일 삭제로 해결하지 않는다.

## 배포 공통 조건

GitHub 인증/원격 확인 → 관련 검사 → Production 빌드/하위경로·자산 검증 → 목적 파일만 커밋 → Pages push → Actions 성공 → 공개 release.json·번들 일치·실제 화면 확인. 앱에 버전·최근 수정 KST 시각이 갱신되어야 한다.

이번 수정은 모바일 Safari·Chrome 사용성 회복이 최우선이다. Production 배포 후 앱 내부 버전과 최근 수정 시각을 갱신하고, 실제 공개 URL에서 새 버전·디자인·터치 동작이 모두 반영됐는지 확인하기 전에는 완료라고 보고하지 마라.
