# Git 보안 운영

## 공개 노출 억제와 본인 전용 접근의 구분

- 화면의 작은 FINETUNE 워터마크는 소유·개인 학습용 안내이며 인증이나 복사 방지가 아니다. 선택·복사·음성·터치·스크롤을 막지 않고 콘텐츠와 별도 줄에 표시한다.
- 모든 정적 HTML에 `noindex, nofollow, nosnippet, noimageindex`를 넣고 Production 감사에서 누락된 경로를 차단한다. 검색엔진의 자발적 준수 및 재수집이 필요하며, 직접 URL·악성 수집·공개 Git 저장소 접근은 차단하지 않는다. noindex를 읽지 못하게 하는 robots.txt 차단은 추가하지 않는다.
- 배포 감사는 기존 비밀값·서버·개인키·DB·소스맵 차단에 더해 원본 TS/Python, 백업/압축 파일 및 외부·인라인 sourceMappingURL도 거절한다. 임의 백업 파일명 전부를 탐지한다고 보장하지 않으며, 사용자 학습 기록은 배포 입력에 절대 넣지 않는다.
- 공개 라이선스 사전의 출처·이용 허가는 유지한다. 워터마크나 CONTENT-NOTICE.txt가 원자료의 공개 라이선스를 취소하거나 독점권을 만들지 않는다.
- 실제 본인 전용 접근은 Cloudflare Access 등 서버 측 보호가 모든 HTML/JS/CSS/JSON·Preview에 적용된 뒤 익명 직접 URL로 검증해야 한다. 기존 Pages와 저장소는 별도 종료/Private 승인 전까지 공개 상태다.
- Cloudflare 카드·약관·초과 사용료 동의는 사용자가 직접 검토·완료한다. 계정 활성화만으로 접근 보호 또는 배포 완료로 보고하지 않는다.

## 현재 감사 범위

`pnpm security:audit`는 현재 main의 추적 파일과 표준 무시 대상이 아닌 미추적 파일 이름을 검사하고, 공개 `origin/gh-pages` 트리에서 서버·소스맵·환경파일·고신뢰 비밀 패턴을 차단한다. 오류가 나면 배포 전에 중단한다. 공개 Pages에 필요한 `public/data`와 번들만 허용하며, 학습 기록·서버 코드·환경변수는 저장소와 Pages에 넣지 않는다.

현재 점검에서 확인한 공개용 값은 앱 ID·OAuth URL 같은 공개 식별자뿐이다. `JWT_SECRET`, `DATABASE_URL`, `BUILT_IN_FORGE_API_KEY`, `OPENAI_API_KEY`는 서버 런타임 환경변수로만 제공해야 한다.

## 커밋 전 규칙

- `.env`, `.env.*`, 자격증명·토큰 파일, DB 덤프는 커밋하지 않는다. 공유 가능한 키 이름만 `.env.example`에 기록한다.
- 실수로 비밀값을 커밋했다면 파일을 지우는 것만으로 끝내지 말고 즉시 키를 폐기·교체하고 Git 이력 정리를 별도로 수행한다.
- 공개 Pages는 정적 학습 데이터 배포 대상이다. 로그인 토큰·학습자 식별자·서버 API 키를 정적 자산에 포함하지 않는다.
- 소스맵은 공개 배포하지 않는다. 번들에서 서버 비밀 환경변수 이름이나 값이 보이면 배포를 중단하고 빌드 경로를 고친다.

감사 스크립트는 값 자체를 출력하지 않고 파일과 유형만 보고한다. 기존 사용자 작업 파일은 삭제하거나 되돌리지 않는다.
