# Git 보안 운영

## 현재 감사 범위

`pnpm security:audit`는 현재 main의 추적 파일과 표준 무시 대상이 아닌 미추적 파일 이름을 검사하고, 공개 `origin/gh-pages` 트리에서 서버·소스맵·환경파일·고신뢰 비밀 패턴을 차단한다. 오류가 나면 배포 전에 중단한다. 공개 Pages에 필요한 `public/data`와 번들만 허용하며, 학습 기록·서버 코드·환경변수는 저장소와 Pages에 넣지 않는다.

현재 점검에서 확인한 공개용 값은 앱 ID·OAuth URL 같은 공개 식별자뿐이다. `JWT_SECRET`, `DATABASE_URL`, `BUILT_IN_FORGE_API_KEY`, `OPENAI_API_KEY`는 서버 런타임 환경변수로만 제공해야 한다.

## 커밋 전 규칙

- `.env`, `.env.*`, 자격증명·토큰 파일, DB 덤프는 커밋하지 않는다. 공유 가능한 키 이름만 `.env.example`에 기록한다.
- 실수로 비밀값을 커밋했다면 파일을 지우는 것만으로 끝내지 말고 즉시 키를 폐기·교체하고 Git 이력 정리를 별도로 수행한다.
- 공개 Pages는 정적 학습 데이터 배포 대상이다. 로그인 토큰·학습자 식별자·서버 API 키를 정적 자산에 포함하지 않는다.
- 소스맵은 공개 배포하지 않는다. 번들에서 서버 비밀 환경변수 이름이나 값이 보이면 배포를 중단하고 빌드 경로를 고친다.

감사 스크립트는 값 자체를 출력하지 않고 파일과 유형만 보고한다. 기존 사용자 작업 파일은 삭제하거나 되돌리지 않는다.
