# FT 브랜드 자산

사용자가 2026-10-14 제공한 `파인튠 프리미엄 앱 브랜딩.png` / ChatGPT 공유 m_6ace56589c188191a30edb79f5042883 기반. 원본은 사용자 Downloads에 보존했다. 상표 독점권·제3자 권리 조사를 완료했다고 주장하지 않는다.

내장 imagegen으로 남색 FT 사각 아이콘 파생본을 만들었다. 최종 프롬프트: 원본 상단의 cyan/white/violet 접힌 FT와 빛나는 slider를 보존하고, 글자·한국어·콜라주·흰 여백 없이 남색 사각 아이콘만 재현한다. 새 브랜드를 재설계하지 않는다.

`scripts/build-brand-assets.mjs <승인된 사각 PNG>`는 기존 Expo image-utils로 크기만 조정한다. 앱1024 / favicon64 / Apple180 / 공유512 PNG. 기존 파일은 삭제하지 않았다. 홈은 작은 FT 아이콘과 native FineTune 텍스트이며, 네이티브 설치 앱 빌드·스토어 출시는 이 웹 릴리스와 별도다. 기존 홈 화면 아이콘·메신저 미리보기의 기기/서비스 캐시 갱신은 강제할 수 없다.
