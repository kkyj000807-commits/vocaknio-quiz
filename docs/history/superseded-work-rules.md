출처 `AGENTS.md`:

출처 `docs/AI_WORK_RULES.md`:

> 매회 P0(정답/기록/데이터/사용 차단) → P1(매일 학습·문제 품질·모바일) → P2(적응형·sense·기출 환류) → P3(구조·자동화) 순으로 작은 batch 하나를 선택한다.

> 모든 코드 수정 작업에 다음 문장을 적용한다. 코드 수정에서 멈추지 말고 실제 Production 배포까지 진행한 후 공개 URL에서 이번 변경사항을 검증하라. 실제 URL 검증 전에는 완료라고 보고하지 마라.

> Production 수정·배포가 실제 공개 URL에 성공할 때마다 `0.1`씩 올린다.

> 한 batch는 조사→실제 데이터→단어장/문제풀이 UI→문항→검사→회귀→공개 확인까지 닫는다.
