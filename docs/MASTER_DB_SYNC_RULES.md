# 2027 편입 마스터 DB 연동 규칙

이 저장소는 `2027 편입 시스템`의 소비자이자 파생 데이터 생산자다. 편입 관련 작업은 아래 흐름을 기본값으로 사용한다.

`접근 가능한 최신 원본 확인 → 마스터 DB와 비교 → 변경 분류 → 작업/검증 → 재사용 가능한 변경 동기화 → export/cache 재생성 → 동기화 감사`

## 기준과 우선순위

- 중앙 기준은 `2027 편입 마스터 DB`다. 앱에서 별도의 canonical 어휘를 새로 만들어 분기시키지 않는다.
- 충돌 시 `공식 최신 원문 → 마스터 DB의 검증된 최신값 → 사용자 실제 기출/오답 기록 → 검증된 파생 데이터 → 과거 snapshot/임시 파일` 순으로 판단한다.
- 날짜만으로 최신성을 확정하지 않는다. 적용연도, 발표일, 시행일, 자료상태, 출처, 검증상태를 함께 비교한다.
- 2026·2027 및 과거 기출/참고자료는 서로 덮어쓰지 않는다.

## 작업 전 최소 확인

- 현재 작업과 관련된 학교정보, 시험스타일, 기출기록, 오답로그, 주간계획, 어휘/숙어 원본, FINAL VOCA, VOCA NEXUS export/sync를 선택적으로 확인한다.
- 동일 항목은 `신규 / 수정 / 동일·중복 / 충돌 / 구버전 / 미확인`으로 분류한다.
- 같은 입력을 다시 처리해도 중복 생성되지 않게 idempotent하게 구현한다.
- 중앙 DB 위치나 연결을 실제로 확인하지 못했다면 접근했다고 말하지 않는다. 마지막 동기화 시점을 확인하고 `stale`, `sync_required`, `unverified` 중 맞는 상태를 남긴다.

## 책임 경계

- `학교정보`: 모집요강, 자격, 반영비율, 일정, 모집단위 등 공식 전형 사실.
- `시험스타일DB`: 기출에서 관찰한 구조, 시간압박, 영역 비중, 함정, 변화와 근거 수준.
- `기출기록`: 사용자의 학교·연도·점수·시간·영역별 오답·총오답.
- `오답로그`: 오류 유형, 원인, 정답 근거, 재발 방지, 복습·반복 상태.
- `어휘 원본 DB`: 단어·숙어 canonical 데이터. VOCA NEXUS는 원칙적으로 이를 읽어 앱용 export/cache/index를 생성한다.

공식 사실과 분석적 시험 성향을 같은 필드에 섞지 않는다. 식별자는 대학 공식명, 학년도, 전형 유형, 시험 연도, lemma, 숙어 canonical form을 정규화한다.

## 자동 반영과 보호

- 출처와 의미가 명확하고, 기존 값보다 최신·정확하며, 재사용 가치가 있고, 충돌 판정이 가능한 정보만 기준 DB 반영 대상으로 삼는다.
- 검증된 어휘 원본이 바뀌면 관련 VOCA NEXUS export/cache/index와 schema/test/UI까지 이어지는지 확인한다.
- 추측, 임시 가설, 검증되지 않은 커뮤니티 정보는 확정 사실로 저장하지 않는다.
- 충돌을 임의 해소하거나 기존 사용자 값, 학습 기록, 데이터 파일을 덮어쓰지 않는다. 해결되지 않으면 `충돌/재검증 필요`로 보존한다.
- 대량 삭제, destructive migration, 기존 데이터 재생성은 영향과 안전한 병합 경로를 확인하기 전 실행하지 않는다.

## 출처와 변경이력

중요 데이터는 가능한 범위에서 source/source_url 또는 원본 파일, 확인일, 발표일, 적용 학년도·기간, 확정·잠정·참고 상태, 마지막 변경 시각과 이유를 추적한다. 파생값은 `원자료 → 정제 데이터 → 계산/파생값 → 분석 → 앱 표시값`으로 역추적할 수 있어야 한다.

## 종료 전 동기화 감사

1. 재사용 가능한 새 정보가 기준 DB 반영 대상에서 빠지지 않았는가.
2. 기존 값과 충돌·중복되지 않는가.
3. 원본 변경이 파생 데이터와 앱 export/cache에 반영됐는가.
4. 검증되지 않은 추정이 확정 데이터에 섞이지 않았는가.
5. 필요한 출처와 변경이력이 남았는가.
6. 접근하지 못한 외부 DB를 최신으로 가장하지 않았는가.
