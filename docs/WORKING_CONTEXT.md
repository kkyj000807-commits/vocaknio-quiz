# VOCA NEXUS 현재 작업 상태

이 문서는 대화 원문을 쌓는 기록이 아니라, 다음 작업에서 즉시 이어가기 위한 최신 사실만 유지한다.

## 단일 작업실 규칙

- Codex 주 작업실은 고정된 `VOCA NEXUS 통합 작업실` 하나다.
- VOCA 작업을 위해 새 대화, 보조 작업, 비중복 분석 작업을 만들지 않는다.
- 조사, 구현, 검증, 배포, 브리핑을 모두 같은 작업실에서 이어간다.
- 컨텍스트가 축약되면 이 문서, `docs/AI_WORK_RULES.md`, `git status`를 먼저 읽고 계속한다.
- 과거 대화 전체를 다시 탐색하지 않고 이 문서의 현재 사실을 기준으로 삼는다.
- 별도 작업이 꼭 필요하면 먼저 사용자에게 이유와 범위를 설명하고 승인을 받는다.

## 사용자 목표

- 알바 휴식이나 식사 중 5~10분 사용하는 편입영어 보조 학습 앱이다.
- 기능 수보다 정답 판정, 뜻, 동의어의 정확성이 우선이다.
- 기본 학습은 10문제로 빠르게 시작할 수 있어야 한다.
- 크롬과 사파리에서 같은 기본 화면과 안정적인 학습 흐름을 제공해야 한다.
- 코드 수정만이 아니라 실제 공개 사이트에 반영되고 동작해야 완료다.

## 현재 구현

- VOCA NEXUS v1.4 정본: 38,163개 단어.
- 일반 퀴즈와 오답 복습은 공통 v1.4 퀴즈 엔진을 사용한다.
- 홈의 v1.4 범위에서 실제 퀴즈로 진입할 수 있다.
- GitHub Pages 기본 경로는 `/vocaknio-quiz/`다.
- 밝은 테마 기본 배경은 `#f5f5fa`, 표면은 `#ffffff`, 카드는 `#eeeef8`이다.
- 새 브라우저의 기본값은 밝은 테마다.
- 크롬·사파리의 구버전 테마 저장값은 새 키로 분리했다.
- 저장소 접근이 실패해도 테마 로딩이 빈 화면으로 멈추지 않는다.

## 검증 상태

- Expo 웹 내보내기: 통과.
- Pages 경로와 참조 자산 15개: 누락 0개.
- 테마 파일 린트: 통과.
- 전체 타입 검사는 기존 `tests/vocab.test.ts`가 삭제된 구 API 3개를 import하여 실패한다.
- 위 전체 타입 오류 3개는 현재 테마·배포 변경과 분리된 기존 문제다.

## 작업 트리 주의사항

- 여러 기존 미커밋 파일과 분석 산출물이 남아 있다.
- 사용자가 만든 변경을 reset, 삭제, 일괄 커밋하지 않는다.
- 작업 목적과 직접 관련된 파일만 명시적으로 골라 커밋한다.
- `analysis/`, `build/`, `output/`, `qa_claude/`, `tmp/`, `vocab_project/`는 현재 자동 정리하지 않는다.

## 다음 우선순위

1. 사용자가 새로 요청한 동작을 이 작업실에서 바로 재현한다.
2. 수정 전 기존 흐름과 저장 데이터 호환성을 확인한다.
3. 관련 전용 검사와 실제 사용자 흐름을 검증한다.
4. 공개 배포 후 크롬과 가능한 범위의 사파리 호환성을 확인한다.
5. 브리핑에는 시간, 변경, 배포, 막힘, 다음 한 가지만 간결하게 남긴다.

## 표준 검증 명령

- v1.4 타입 검사: `node_modules\.bin\tsc.cmd -p tsconfig.vocab-v1.4.json`
- v1.4 테스트: `node_modules\.bin\vitest.cmd run --config vitest.vocab-v1.4.config.ts`
- 데이터 감사: `node_modules\.bin\tsx.cmd scripts\audit-quiz-engine-v1.4.ts`
- 웹 내보내기: `node_modules\.bin\expo.cmd export --platform web --output-dir <빈 임시 폴더>`

문서를 갱신할 때는 완료 이력을 계속 덧붙이지 말고 위 현재 사실을 교체한다.
