## 적응형·비중복 출제

- 최근 세션 문항은 후보가 충분하면 다음 세션에서 즉시 반복하지 않는다.
- 세션의 최소 75%는 전체 범위 저노출 문항, 최대 25%는 약점 복습으로 구성한다.
- 같은 표제어와 같은 개념이 한 세션에 몰리지 않게 한다.
- 정답·오답·패스·응답한 오답을 문제별로 저장한다.
- 반복해서 고른 오답과 같은 표제어·개념은 다음 세션 약점 슬롯에서 우선한다.
- 숙어·V601처럼 동의어 정답이 부족한 범위는 검증된 한국어 뜻 4지선다로 자동 전환해 같은 몇 단어만 반복되는 문제를 막는다.
- 실제 데이터 모의 실행에서 숙어·V601·V502·부록 각각 10세션×20문항이 200개 고유 문항, 인접 세션 중복 0으로 생성됐다.
- 적응형 기록은 현재 브라우저 로컬 저장소 기반이다. Safari·Chrome·기기 간 동기화는 아직 없다.
- 혼동 기록은 출제 대상 우선순위에 반영하지만 개인별 오답 선지 구성까지 바꾸지는 않는다.
