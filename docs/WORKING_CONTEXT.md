## 프로젝트 판단 기준

- 사용자 목적: 알바 휴식·식사 중 5~10분 사용하는 편입영어 보조 학습 앱이다. 정답 신뢰성이 기능 수보다 우선한다.
- v1.4 전환 이유: 기존 9,517개 데이터와 화면별 퀴즈 생성은 다의어 뜻 혼합, 중복 정답, 잘못된 선지 뜻 표시 위험이 있었다. 38,163개 정본과 뜻 단위 동의어 연결, 공통 판정 엔진으로 이를 한곳에서 통제한다.
- 현재 위치: 정본·공통 엔진 준비에 이어 퀴즈, 오답 복습, 홈 범위 연결까지 끝났다. 저장 번호 마이그레이션과 나머지 화면의 공통 동의어 표시가 후속 단계다.
- 이미 해결됨: 문자열 동등 비교 판정, 전역 `VOCAB.find()` 기반 선지 뜻 추정, 구형 `d01` 범위로 인한 퀴즈 진입 실패.
- 우선순위: 저장 번호 백업·마이그레이션 → 레거시 테스트 제거/전환 → 단어장·결과·북마크·오답 표시 통합 → 실제 기기 성능과 짧은 세션 UX.

1. 기존 사용자 작업과 미커밋 변경을 덮어쓰지 않는다.
